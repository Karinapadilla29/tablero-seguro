# Tablero de Seguros — Streamlit

Tablero interactivo desarrollado como parte del Diplomado en Machine Learning para Seguros de la Facultad de Ciencias, UNAM.

## Descripción

La aplicación permite analizar una cartera de seguros mediante:

- Filtros por cobertura, sexo, uso, combustible y edad.
- Indicadores de exposición, número de siniestros, frecuencia, severidad y prima pura.
- Gráficas para visualizar indicadores técnicos de la cartera.
- Cotizador de seguros con tres resultados: prima empírica, prima GLM y precio final.

## Ejecución local

1. **Clonar el repositorio:**

```bash
git clone https://github.com/Karinapadilla29/tablero-seguro.git
```

2. **Entrar a la carpeta:**

```bash
cd tablero-seguro
```

3. **Instalar las dependencias:**

```bash
pip install -r requirements.txt
```

4. **Ejecutar la aplicación:**

```bash
streamlit run app_streamlit.py
```
